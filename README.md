# Cienie Oli

Mobilny katalog kolekcji cieni do powiek, przygotowany jako statyczna aplikacja dla GitHub Pages.

## Funkcje

- katalog cieni z wyszukiwaniem i statusami,
- grupowanie według firmy, serii, wykończenia oraz tagów,
- palety i miejsca przechowywania z przeciąganiem,
- kolor HEX i własna tekstura ze zdjęcia,
- prosty mieszalnik kolorów,
- eksport i import pełnej kolekcji,
- zapis lokalny oraz działanie offline.

## Publikacja na GitHub Pages

1. Utwórz nowe repozytorium i skopiuj do niego wszystkie pliki z tego katalogu.
2. W GitHub otwórz **Settings → Pages**.
3. Wybierz **Deploy from a branch**, gałąź `main` i katalog `/ (root)`.
4. Po zapisaniu GitHub pokaże adres strony.

Wszystkie dane są przechowywane lokalnie w przeglądarce. Do przenoszenia danych między urządzeniami służy eksport i import pliku JSON.
